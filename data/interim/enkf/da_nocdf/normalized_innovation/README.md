# Normalized Innovation Directory

**Author:** M. El Aabaribaoune

## Purpose
Native-event diagnostics extracted from the EnKF assimilation system.

## Contents
Includes native-event and daily bridge products for:
- observation_frequency
- signed increment
- absolute increment
- innovation
- normalized innovation
- forecast variance
- analysis residual

## Timing Rule
**Important Methodological Note:** LIS HIST daily `_tavg` timestamps use the validated daily convention; native EnKF event timestamps are NOT shifted using the HIST -1 day rule.
**Important:** Files in this directory are generated by project scripts. Do NOT manually modify generated NetCDF products. Regenerate through the corresponding preprocessing script.
