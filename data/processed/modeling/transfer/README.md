# TRANSFER Modeling Datasets

**Author:** M. El Aabaribaoune

This directory contains the Block 2 TRANSFER datasets, used to model how the DA-modified land trajectory propagates from the surface-soil-moisture assimilation source into deeper soil moisture and land-surface flux responses.

## Structure
- `da_cdf/`: Transfer dataset for the DA-CDF experiment
- `da_nocdf/`: Transfer dataset for the DA-NoCDF experiment

For complete details, see `docs/datasets/modeling_dataset_contract.md`.
