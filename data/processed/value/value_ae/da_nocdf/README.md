# Da Nocdf Directory

**Author:** M. El Aabaribaoune

## Purpose
Contains Block 3 Value canonical targets.

## Canonical Metric
`value_ae`

**Formula:**
`abs(ET_OPL - ET_GLEAM) - abs(ET_DA - ET_GLEAM)`

**Unit:**
`mm day-1`

## Interpretation
- `>0`: DA agrees more closely with GLEAM than OPL.
- `<0`: DA agrees less closely with GLEAM than OPL.

## Reference
GLEAM v4.3a. GLEAM is an external evaluation reference, NOT ground truth.

## Support
- **Common harmonized availability support**: 4110 cells/day.
- **High-land-coverage sensitivity subset**: 3871 cells/day. The latter is NOT a second target.

For `da_cdf` and `da_nocdf` directories:
The NetCDF variable is strictly `value_ae`. The experiment identity is stored internally in metadata.
**Important:** Files in this directory are generated by project scripts. Do NOT manually modify generated NetCDF products. Regenerate through the corresponding preprocessing script.
