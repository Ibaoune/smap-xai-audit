# Datasets Construction

**Author:** M. El Aabaribaoune

This directory covers the construction of the canonical ML-ready datasets:
- SOURCE
- TRANSFER
- VALUE

Preprocessing produces canonical scientific variables. Dataset construction assembles those variables into leakage-controlled modeling tables. Modeling begins only after those tables are locked.
