# Qc Directory

**Author:** M. El Aabaribaoune

## Purpose
Contains reproducible quality-control and audit workflows.

## Contents
The directory distinguishes between:
- Scientific QC
- Preprocessing validation
- Plotting scripts
- Cross-target audits
- Value audits

## Conventions
**Explicit Warning:** QC outputs (figures, tables, reports) should NOT be confused with canonical training data.
